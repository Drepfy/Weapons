# Weapons

Paper server plugins.

| Module | Description |
| --- | --- |
| [`moderation`](moderation/README.md) | **StaffModeration**: bans, mutes, voice-chat mutes, warnings and kicks with a persistent punishment history. |

## Building

Requires JDK 21 or newer.

```sh
./gradlew build
```

The plugin jar is written to `moderation/build/libs/StaffModeration-<version>.jar`.
